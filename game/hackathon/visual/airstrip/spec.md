game/public/models/airport.glb
game/public/models/airport_airplane.glb

### Functionality required. 
1. Build the airstrip on the side which is closer to mountain and the last house. 
2. Place the place on the airstrip. 
3. Make sure the airstrip has blinking lights like an airport runway. 
4. The airplane is in an parked state since the weather is an outcast. 
5. Christmas celebratory things like lights can be placed in the airport/airstrip sides to keep the theme of the game.
